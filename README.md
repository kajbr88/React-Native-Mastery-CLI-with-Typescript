# React Native Mastery: Develop 10 Apps with Confidence with CLI & TypeScript | Hitesh Choudhary

This repository contains the project files and code developed during the "React Native Mastery: Develop 10 Apps with Confidence with CLI & TypeScript" course by Hitesh Choudhary on YouTube.

## Course Overview

This course focuses on building proficiency in React Native development using the command-line interface (CLI) and incorporating TypeScript for enhanced code quality and maintainability. Hitesh Choudhary guides learners through the process of developing 10 distinct mobile applications, covering a wide range of practical skills and concepts.

4.  **Navigation:** Implementing different navigation patterns (e.g., Stack Navigator, Tab Navigator).
5.  **Working with APIs:** Fetching and displaying data from external APIs.
6.  **State Management:** Utilizing state management solutions (likely Context API or potentially Redux/Zustand).
7.  **Asynchronous Operations:** Handling asynchronous tasks and promises.
8.  **Native Modules and APIs:** Interacting with device features.
9.  **Building UI Libraries/Components:** Creating reusable UI elements.
10. **Testing:** Implementing unit and/or integration tests.
11. **Deployment:** Understanding the basics of deploying React Native applications to different platforms.
12. **Building 10 Different Applications:** Hands-on projects covering various use cases.

## Getting Started with the Projects

To run the projects in this repository, you will need to have Node.js, npm (or yarn), and the React Native CLI installed on your system.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/kajbr88/React-Native-Mastery-CLI-with-Typescript.git
    ```

2.  **Navigate to a specific project directory (e.g., `/styler02`):**
    ```bash
    cd styler02
    ```

3.  **Install dependencies:**
    ```bash
    npm install  # or yarn install
    ```

4.  **Run the application on your desired platform (iOS or Android):**

    **For iOS:**
    ```bash
    npx react-native run-ios
    ```

    **For Android:**
    ```bash
    npx react-native run-android
    ```

    **Note:** You may need to have Xcode (for iOS) or Android Studio (for Android) set up correctly on your system.
